# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good intent, keep discussion about the work,
and do not harass anyone. Behaviour that makes others unwelcome is not
accepted in issues, pull requests or any other place the project is
discussed.

To report a problem, contact the maintainers privately through the
repository's **Security** tab ("Report a vulnerability"), marking the report
as a conduct matter. Reports are kept confidential.
